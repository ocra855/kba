# 🐎 TURF LOG (ターフログ)

![PWA Ready](https://img.shields.io/badge/PWA-Ready-success)
![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

**TURF LOG** は、競馬の収支と回収率をスマートに管理するための **PWA (Progressive Web App)** です。
「どの馬を買ったか」「いくら勝ったか」を直感的に記録し、あなただけのデータベースを構築します。


## ✨ 特徴 (Features)

* **📊 自動収支計算**: 投資額と払戻額を入力するだけで、瞬時に「収支」と「回収率(%)」を算出。
* **📝 詳細メモ機能**: 軸馬、相手、券種など、改行を含む詳細な買い目メモを記録可能。
* **📱 PWA完全対応**: スマホのホーム画面に追加することで、ネイティブアプリと同様の操作感を実現。
* **✈️ オフライン動作**: Service Workerを搭載し、電波の悪い競馬場内でも履歴の閲覧や入力が可能。
* **🔒 プライバシー重視**: データはブラウザの `LocalStorage` にのみ保存。外部サーバーに送信されないため安心。
* **✏️ 編集・削除機能**: 入力ミスがあっても、個別にデータの修正や削除が可能。
* **🎨 視認性の高いUI**: 勝ち（プラス）は赤、負け（マイナス）は青で色分けし、成績を一目で把握。
