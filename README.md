# kba

🐎 競馬収支管理アプリ
シンプルで使いやすい、PWA対応の競馬収支管理アプリです。 

買い目のメモや金額を入力するだけで、自動的に収支と回収率を計算・グラフ化します。スマホのホーム画面に追加して、オフラインでも使用可能です。


✨ 特徴
📊 自動計算機能: 投資額と払戻額を入力するだけで、収支と回収率(%)を自動計算。
📝 詳細メモ: 「◎イクイノックス」「3連単 10-5-3」など、改行を含む詳細な買い目メモを記録可能。
📱 PWA対応: スマートフォンのホーム画面にインストール可能。ネイティブアプリのような操作感。
✈️ オフライン動作: 電波の悪い競馬場でも、Service Workerにより過去の履歴閲覧や入力が可能。
💾 ローカル保存: データはブラウザの LocalStorage に保存。サーバーに送信されないためプライバシーも安心。
✏️ 編集・削除: 間違えて入力しても、後から個別に編集・削除が可能。
🎨 直感的なUI: 勝ち（プラス）は赤、負け（マイナス）は青で視覚的にわかりやすく表示。


🚀 使い方 (Usage)
入力: レース名、買い目メモ、投資額、払戻額を入力します。
保存: 「記録をつける」ボタンを押すとリストに追加されます。
確認: 画面上部に「通算収支」と「通算回収率」が常に表示されます。
管理: 各カードの「編集」「削除」ボタンで履歴を整理できます。
